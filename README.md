# CollabSpace

Кросплатформена веб-система спільного управління проєктами візуальної колаборації
з вбудованими засобами комунікації.

Магістерська кваліфікаційна робота, спеціальність 123 «Комп'ютерна інженерія».

## Можливості

- Нескінченне спільне полотно: стікери, текст, фігури, зображення, зв'язки
- Режим канбан-подання об'єктів полотна
- Одночасна робота кількох користувачів у реальному часі, курсори й виділення учасників
- Вбудований голосовий зв'язок між учасниками дошки
- Вбудований текстовий чат
- Робота з десктопа й мобільного пристрою

## Структура репозиторію

```
client/    веб-клієнт (React + TypeScript + Konva)
server/    сервер застосунків (Node.js + Express + WebSocket)
shared/    спільні типи протоколу для клієнта й сервера
bench/     емулятор клієнтів і сценарії навантажувальних експериментів
docs/      технічне завдання, план, журнал рішень, матеріали записки
```

## Запуск

Потрібні Docker Desktop і Node.js 20+.

```bash
cp .env.example .env
docker compose up -d      # PostgreSQL, Redis, coturn
npm install
npm run dev
```

Клієнт відкривається на `http://localhost:5173`, сервер слухає `http://localhost:3000`.
