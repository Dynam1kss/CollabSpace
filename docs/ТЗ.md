# Технічне завдання на магістерську кваліфікаційну роботу

**Тема:** Кросплатформена веб-система спільного управління проєктами візуальної колаборації користувачів та вбудованими засобами комунікації

## 1. Підстава для виконання

Наказ по університету про закріплення тем магістерських кваліфікаційних робіт.

## 2. Мета роботи

Підвищення ефективності спільної роботи розподілених груп користувачів над візуальним поданням проєктних задач шляхом розроблення методу синхронізації спільного стану полотна з керуванням областю інтересу клієнта та інтеграції вбудованих засобів голосової й текстової комунікації в єдине веб-середовище.

## 3. Об'єкт і предмет дослідження

**Об'єкт дослідження** — процеси синхронізації спільного стану та обміну даними в багатокористувацьких веб-системах візуальної колаборації.

**Предмет дослідження** — методи та програмні засоби синхронізації спільного полотна й інтегрованої голосової та текстової комунікації в кросплатформеній веб-системі.

## 4. Вихідні дані до роботи

| Параметр | Значення |
|---|---|
| Кількість одночасних учасників однієї дошки | до 25 (цільове), до 50 (навантажувальне тестування) |
| Кількість учасників голосового каналу | до 6 (топологія mesh) |
| Кількість об'єктів на дошці | до 1000 |
| Цільова затримка відображення змін (p95) | не більше 150 мс у локальній мережі |
| Підтримувані платформи | Windows, Linux, macOS (десктопні браузери), Android, iOS (мобільні браузери) |
| Підтримувані браузери | Chrome, Edge, Firefox, Safari — дві останні мажорні версії |
| Спосіб розгортання | контейнеризоване середовище Docker Compose |

## 5. Завдання, що підлягають вирішенню

1. Провести аналіз предметної області спільної візуальної колаборації, дослідити наявні системи-аналоги, виявити принципи їх побудови, переваги та недоліки.
2. Дослідити методи синхронізації спільного стану в розподілених системах реального часу — операційні трансформації (OT) та безконфліктні реплікованi типи даних (CRDT), обґрунтувати вибір методу.
3. Розробити архітектуру кросплатформеної веб-системи, модель даних полотна та протокол обміну повідомленнями між клієнтами й сервером.
4. Розробити метод синхронізації спільного стану полотна з керуванням областю інтересу клієнта, який зменшує обсяг переданих даних при зростанні кількості учасників.
5. Спроєктувати та реалізувати підсистему вбудованої комунікації — голосовий канал на технології WebRTC та текстовий чат, а також механізм прив'язки параметрів голосового каналу до просторового контексту полотна.
6. Реалізувати програмний продукт, забезпечити його кросплатформеність засобами адаптивного інтерфейсу та технології Progressive Web Application.
7. Виконати функціональне та навантажувальне тестування системи, провести експериментальне порівняння стратегій синхронізації, оцінити ефективність запропонованих рішень.
8. Сформулювати обмеження отриманого рішення та визначити напрями подальших досліджень.

## 8. Наукова новизна очікуваних результатів

Удосконалено метод синхронізації спільного стану полотна на основі безконфліктних реплікованих типів даних за рахунок керування областю інтересу клієнта, що, на відміну від відомих рішень із широкомовним розсиланням оновлень, дозволяє зменшити обсяг переданих даних при зростанні кількості одночасних учасників.

Запропоновано спосіб прив'язки параметрів голосового каналу до просторового контексту спільного полотна, що забезпечує природніше розділення паралельних обговорень у межах однієї робочої області.
